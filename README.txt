วิธีใช้งาน
==========
1. เปิดไฟล์ index.html ด้วยเบราว์เซอร์ (Chrome / Safari / Edge) ได้ทันที

2. ใส่รูปภาพของคุณ
   - นำรูปภาพไปวางในโฟลเดอร์ images/ แล้วตั้งชื่อไฟล์เป็น 1.jpg, 2.jpg, ... 10.jpg
   - ถ้ายังไม่ใส่รูป เว็บจะแสดงกรอบสีพาสเทลสวยงามแทนโดยอัตโนมัติ ไม่มีไอคอนรูปหาย

3. ใส่เพลง
   - นำไฟล์เพลง (เช่น .mp3) มาวางในโฟลเดอร์เดียวกับ index.html แล้วตั้งชื่อว่า music.mp3
   - เพลงจะเริ่มเล่นอัตโนมัติหลังผู้ใช้แตะเปิดซองจดหมาย (ตามข้อกำหนดของเบราว์เซอร์มือถือที่ต้องมีการโต้ตอบก่อนเล่นเสียง)

4. แก้ไขข้อมูล
   - ชื่อแฟน/ข้อความในจดหมาย: แก้ได้ในไฟล์ index.html (ส่วน letterMessage ใน script.js สำหรับข้อความหลัก)
   - วันที่เริ่มคบ: แก้ได้ที่ตัวแปร startDate ในไฟล์ script.js (ปัจจุบันตั้งเป็น 01/10/2025)

โครงสร้างไฟล์
=============
index.html   โครงสร้างหน้าเว็บทั้งหมด
style.css    ธีมสี ฟอนต์ และแอนิเมชันทั้งหมด
script.js    การทำงานแบบโต้ตอบ (เปิดซอง, พิมพ์ดีด, นับเวลา, เอฟเฟกต์ต่าง ๆ)
images/      ใส่รูปภาพความทรงจำ 10 รูป (1.jpg - 10.jpg)
music.mp3    ใส่ไฟล์เพลงพื้นหลัง (ผู้ใช้ต้องเพิ่มเอง)
