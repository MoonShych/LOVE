# วิธีใช้งานเว็บไซต์ครบรอบ ❤️

## 1. ใส่ไฟล์เสียงและรูปภาพ
วางไฟล์ของคุณลงในโฟลเดอร์ `assets/` ให้ตรงชื่อนี้:

```
assets/
├── song.mp3      → เพลงหลัก (เล่นตอนเปิดซอง)
├── voice.mp3      → ข้อความเสียง (หน้า 7)
├── unlock.mp3     → เสียงตอนใส่รหัสถูก
├── click.mp3      → เสียงกดปุ่มตัวเลข
├── whoosh.mp3      → เสียงม่านหัวใจเลื่อน
├── paper.mp3      → เสียงเปิดซอง/กระดาษ
└── images/
    ├── 1.jpg
    ├── 2.jpg
    ├── 3.jpg
    └── ... (ใส่ต่อเนื่องเป็นตัวเลข ระบบจะหารูปให้เองสูงสุด 20 รูป)
```

ถ้าไฟล์ไหนไม่มี เว็บจะไม่พังและไม่มี error โผล่ให้เห็น — แค่จะไม่มีเสียง/รูปนั้นแสดงเฉย ๆ

## 2. แก้ไขข้อมูลส่วนตัว
เปิดไฟล์ `script.js` แล้วแก้ตรงบนสุดของไฟล์ (ในส่วน CONFIG):

- `CORRECT_PIN` — รหัส 6 หลักสำหรับปลดล็อกหน้าแรก (ค่าเริ่มต้น `011025`)
- `RELATIONSHIP_START` — วันที่เริ่มคบกัน สำหรับตัวนับเวลาแบบเรียลไทม์
- `LETTER_TEXT` — ข้อความจดหมายรัก (หน้า 4)
- `ENDING_TEXT` — ข้อความปิดท้าย (หน้า 8)

## 3. เปิดเว็บไซต์
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์บนมือถือหรือคอมพิวเตอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม (ไม่มี framework, ไม่ต้อง build)

## โครงสร้างหน้า
1. Lock Screen — ใส่ PIN ด้วยคีย์แพดที่สร้างเอง (ไม่ใช้ `<input>`)
2. Heart Curtain — ม่านหัวใจเต็มจอ
3. Envelope — แตะเพื่อเปิดซอง เริ่มเพลง
4. Love Letter — จดหมายพิมพ์ทีละตัวอักษร
5. Gallery — เลื่อนดูรูปความทรงจำ
6. Anniversary Counter — นับเวลาที่อยู่ด้วยกันแบบเรียลไทม์
7. Voice Message — ข้อความเสียง (เพลงหลักจะเบาลงอัตโนมัติ)
8. Ending — ข้อความปิดท้าย + ปุ่ม "กอดหน่อย"
