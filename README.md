# Happy Anniversary 💌 — Interactive Love Story

เว็บเซอร์ไพรส์วันครบรอบ ทำด้วย HTML5 + CSS3 + Vanilla JavaScript ล้วน ๆ (ไม่มี framework)

## วิธีใช้งาน

### 1. ใส่รูปและเสียงของคุณเอง
ใส่ไฟล์ลงในโฟลเดอร์ `assets/` ตามนี้:

```
assets/
  images/1.jpg ... 10.jpg   ← รูปแฟน 10 รูป (ถ้ายังไม่ใส่ จะโชว์การ์ด placeholder แทน)
  music/song.mp3            ← เพลงที่จะเล่นหลังปลดล็อก
  voice/voice1.mp3          ← เสียงอัดที่อยากบอกเธอ
  letter/letter.txt         ← ข้อความจดหมายรัก (แก้ไขได้เลย มีตัวอย่างให้แล้ว)
```

ถ้ายังไม่มีไฟล์บางอย่าง เว็บจะยังเปิดได้ปกติ ไม่พัง (แค่จะไม่มีเสียง/รูปในส่วนนั้น)

### 2. ตั้งค่ารหัสผ่านและวันที่
แก้ไขได้ที่ด้านบนของ `js/app.js` ในส่วน `CONFIG`:

```js
const CONFIG = {
  password:  "011025",              // รหัสตัวเลข (แสดงเป็นปุ่มกด ไม่ใช่พิมพ์)
  startDate: "2025-10-01T00:00:00", // วันที่เริ่มความสัมพันธ์
  hint:      "💭 Hint : วันที่ที่ทุกอย่างเริ่มต้น",
  ...
};
```

### 3. เปิดเว็บ
**สำคัญ:** ควรเปิดผ่าน local server (ไม่ใช่ดับเบิลคลิกไฟล์ index.html ตรง ๆ)
เพราะฟีเจอร์โหลดจดหมายจาก `letter.txt` ต้องใช้ `fetch()` ซึ่งเบราว์เซอร์บล็อกเวลาเปิดไฟล์แบบ `file://`
(ถ้าเปิดตรง ๆ เว็บจะยังทำงานได้ แต่จดหมายจะใช้ข้อความตัวอย่างสำรองแทน)

วิธีเปิด local server ง่าย ๆ (เลือกอย่างใดอย่างหนึ่ง):

```bash
# Python
python3 -m http.server 8000

# Node.js
npx serve .
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8000`

หรืออัปโหลดทั้งโฟลเดอร์ขึ้น hosting ฟรี เช่น Netlify / Vercel / GitHub Pages แล้วส่งลิงก์ให้แฟนเปิดจากมือถือได้เลย

## ฟีเจอร์

- 🔐 ระบบล็อกด้วย Keypad (ไม่มี input ไม่มี keyboard เด้ง)
- 💗 Heart Portal — ทรานซิชันปลดล็อกแบบซีนีมาติก
- ⏱️ Love Timer นับเวลาที่อยู่ด้วยกันแบบเรียลไทม์
- 💌 ซองจดหมายเปิดได้ พร้อม Typewriter Effect
- 🖼️ Memory Gallery แบบ Mobile Gallery เต็มจอ / ปัดซ้าย-ขวา / ซูม
- 🎤 Voice Message เล่นพร้อมเพลงพื้นหลังได้
- 🎵 เพลงพื้นหลังเล่นวนหลังปลดล็อก เปิด/ปิดได้
- 🌸 Ambient effect: หัวใจลอย / ประกาย / Parallax ตอนเอียงมือถือ
- 🎬 Final Ending 5 สเตจ: ฝนหัวใจ → กอด (สั่นมือถือ) → รวมเป็นแสง → ข้อความสุดท้าย

แก้ไขสี ฟอนต์ ข้อความต่าง ๆ ได้อิสระใน `css/style.css` และ `js/app.js`
