ใส่ไฟล์เสียงประกอบ (sound effects) ในโฟลเดอร์นี้ — แยกจากเพลงหลัก

ไฟล์ที่รองรับ (ตั้งชื่อไฟล์ตามนี้ หรือแก้ path ใน CONFIG.sounds ใน script.js):

  click.mp3     -> เสียงตอนกดปุ่มทั่วไป
  unlock.mp3    -> เสียงตอนใส่รหัสผ่านถูกต้อง (ปัจจุบันใช้ success.mp3 แทนในหน้า Password)
  paper.mp3     -> เสียงตอนเปิดซองจดหมาย / กระดาษเลื่อน
  magic.mp3     -> เสียงตอนเริ่ม Final Surprise (หัวใจก่อตัว)
  success.mp3   -> เสียงตอนปลดล็อกสำเร็จ และตอนข้อความ "รักอ้วนที่สุด" ปรากฏ

ถ้าไม่มีไฟล์เสียงไหน เว็บไซต์จะไม่ Error — จะแค่ไม่มีเสียงนั้นเล่นเฉย ๆ
